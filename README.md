# Zêblè OS

Projet de conception d'un système d'exploitation mobile ivoirien, original, accessible et évolutif, destiné en priorité aux smartphones économiques.

## État actuel (v0.1)

Ce dépôt est à son stade initial de cadrage. **Aucun code système n'est encore présent.** Aucune compilation n'a été tentée. Aucune compatibilité avec un matériel particulier n'a été démontrée.

Le contenu de ce dépôt se limite à la documentation d'initialisation (voir ci-dessous).

## Vision

Créer progressivement un système d'exploitation mobile ivoirien, original, accessible et évolutif, destiné en priorité aux smartphones économiques.

### Décisions fondatrices du fondateur

- **Cible matérielle** : smartphones économiques.
- **Identité visuelle** : originale.
- **Compatibilité** : applications Android recherchée.
- **Langue initiale** : français.
- **Identité culturelle** : inspiration des signes et de l'alphabet bété, du tapa et de la géométrie inspirée des poids akan.
- **Nom de travail** : Zêblè OS.

## Avertissements importants

- Ce projet est en phase de cadrage et d'étude de faisabilité. Aucune affirmation de fonctionnement, de compilation ou de compatibilité matérielle ne peut être faite à ce stade.
- Aucune protection de sécurité (AVB, SELinux, chiffrement, etc.) ne doit être désactivée pour faciliter les tests.
- La compatibilité avec les applications Android et les services Google (GMS) n'est pas acquise automatiquement avec une base AOSP. Elle ferait l'objet d'études et de tests séparés.
- Le fondateur conserve l'autorité finale sur toutes les décisions techniques et documentaires.
