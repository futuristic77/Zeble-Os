# Décisions techniques — Zêblè OS v0.1

## Objet

Consigner les décisions techniques approuvées, en attente, et les propositions en cours.

## Règle

Chaque décision possède un identifiant unique, un statut et l'autorité ayant approuvé. Le silence ne vaut jamais approbation.

## Procédure pour une nouvelle décision

1. Rédaction d'une proposition détaillée (objectif, état actuel, modification envisagée, justification, avantages, risques, alternatives, retour arrière).
2. Soumission au fondateur pour approbation.
3. Enregistrement dans ce tableau après approbation explicite.
4. Mise à jour du statut : `proposé` → `approuvé` ou `rejeté`.
